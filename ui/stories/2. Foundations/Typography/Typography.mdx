## Fluid responsive typography

- [Fluid typography](https://piccalil.li/tutorial/fluid-typography-with-css-clamp) has been implemented by leveraging the [CSS clamp()](https://developer.mozilla.org/en-US/docs/Web/CSS/clamp) function, resulting in
    - minimal usage of `font-size` declarations,
    - zero media queries.
- Uses the [Utopia fluid type calculator](https://utopia.fyi/) to output the **minimum**, **maximum** and **ideal** font sizes.

For example:
```
body { font-size: var(--webui-font-size-body); }
```
maps to:
```
:root { --webui-font-size-body: var(--type-step-0); }
```
