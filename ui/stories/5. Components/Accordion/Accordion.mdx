# Accordion
- Uses the native HTML `<details>`|`<summary>` elements.
- The `::details-content` pseudo-element is used to animate the accordion opening & closing.

<Canvas of={Accordion.Accordion} />

## Accessibility considerations
- This [article by Scott O'Hara](https://www.scottohara.me//blog/2022/09/12/details-summary.html) gives guidance on using `<details>` &amp; `<summary>` elements, as well as alternative approaches such as [ARIA disclosure widgets](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/).
- This Storybook includes a [`<webui-disclosure>`](/docs/web-components-or-custom-elements-webui-disclosure--docs) Web Component, which uses the ARIA disclosure pattern.
