# Color Scheme Toggle
- Simple CSS-only color scheme toggle component that uses the CSS `color-scheme` property.
- See this [CSS Tricks article](https://css-tricks.com/come-to-the-light-dark-side/) for a detailed explanation.
- The selected color scheme will **not** persist across page reloads. Use the [`<webui-color-scheme-toggle>`](/docs/web-components-or-custom-elements-webui-color-scheme-toggle--docs) Web Component for this.

> NOTE: To see `dark mode` in action, view the component story instead of this docs page, because Storybook docs have a forced `light mode` to ensure legibility.

## Accessibility considerations
- Off-black and off-white colors should be used for the dark and light color schemes, to reduce screen glare.
