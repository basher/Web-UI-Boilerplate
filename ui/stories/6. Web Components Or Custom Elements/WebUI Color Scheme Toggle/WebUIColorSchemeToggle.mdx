# `<webui-color-scheme-toggle>`
- This is a progressive enhancement of the [CSS-only color scheme toggle component](/docs/components-color-scheme-toggle--docs), using the `<select>` element pattern.
- It persists the selected color scheme across page reloads, by saving the preference in `localStorage`.

> NOTE:
> - To see `dark mode` working properly, **view the component story instead of this docs page**.
> - Storybook docs have a forced `light mode` to ensure legibility. This is defined in `./ui/.storybook/preview.js`.
> - See bug https://github.com/storybookjs/storybook/issues/28849.
